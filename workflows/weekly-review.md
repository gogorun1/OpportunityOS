# Weekly review

Read the profile, the last seven local-calendar days of reports, briefs, signals, application outcomes, and workflow memory. Complete the review without repeating full company or career research.

Assess:

- Which outputs led to a decision, useful artifact, interview, or contextual connection?
- Which recommendations were repeats, ineligible, stale, or poorly matched?
- Which agent-doable tasks were incorrectly assigned to the user?
- Which upcoming checkpoint has become actionable?
- Were archives, approvals, delivery states, and receipts recorded accurately?

Produce one short review with completed work, concrete misses and evidence, next week's top three priorities, and proposed configuration changes. Keep observations separate from proposals. Do not silently change confirmed facts, goals, permissions, notification channels, or schedules.

Update run memory with the review and pending decisions. If no user decision is needed, archive quietly according to the configured notification policy.
