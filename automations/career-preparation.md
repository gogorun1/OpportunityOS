# Career Preparation — prompt template

Read AGENTS.md, private/profile.json, private/workspace.json, private/opportunity_os.md, workflows/career-preparation.md, workflows/approval-and-execution.md, and private/memory/career-preparation.md first. Run only if the career lane is enabled.

Check application history and tracker for duplicates. Verify a small number of roles matching the user's priorities using official employer pages; do not rank companies solely by brand or AI keywords. Distinguish hard eligibility, preference, unknowns, and actual evidence fit.

Prepare application packets only for user-selected roles. If none is selected, complete matching and recommend up to three choices with verified responsibilities, constraints, and an evidence-based rationale; do not create fictitious user selection. For selected roles complete the drafts and truthful form answers within the agent's capability, flagging missing personal facts.

Save exact versioned packets in private/applications/ and update the configured Career Tracker in place. Mark Prepared or Awaiting Approval as appropriate. Add a signal only for a concrete role selection or finished packet decision. Route those decisions into the next Daily Radar.

Do not submit, send outreach, connect a mailbox, or spend money. Record timestamped memory with verified roles, dedup keys, packet versions, status, unknowns, and next checkpoint. If Notion fails, keep the completed local packet and a reconciliation record.
