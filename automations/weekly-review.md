# Weekly Review — prompt template

Read AGENTS.md, private/profile.json, private/workspace.json, private/opportunity_os.md, workflows/weekly-review.md, and private/memory/weekly-review.md. Review the past seven user-local calendar days of artifacts and outcomes.

Complete the review described in workflows/weekly-review.md. Report useful decisions and saved work, duplicate or weak recommendations, overdue agent tasks, unresolved approval/receipt inconsistencies, and the next three priorities. Propose specific configuration changes with reasons, but keep goals, facts, authority, channels, and schedules unchanged until the user directs otherwise.

Save the review privately, link relevant Notion packets, and queue any user decisions for the next Radar. Send no email or external messages. Record timestamped memory and notify only when the configured policy calls for it.
